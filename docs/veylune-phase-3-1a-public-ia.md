# Veylune Phase 3.1A - Public IA Rebaseline and Editorial Closure

Captured on 2026-09-19 against the local Shopware storefront and the live Wayfair public discovery structure.

## Result

All 47 governed public routes were re-audited at desktop and mobile sizes. The resulting 94-surface baseline contains 90 current surfaces, zero mixed surfaces, zero broken surfaces, and four explicitly declared commerce decisions.

## Editorial closure

- `/editions` remains the material and release-record surface.
- `/journal` is now a distinct public field-notes surface for materials, making, and spatial studies.
- `/inspiration` is now a distinct room-led discovery surface.
- Public editorial output no longer exposes private-preview language.
- A legacy Shopware SEO URL that captured `/journal` is normalized by the canonical ingress policy without deleting Admin data.

## Evidence

- 47 routes and 94 desktop/mobile surfaces.
- 90 current, 0 mixed, 0 broken, and 4 decision-required surfaces.
- 0 horizontal-overflow surfaces.
- 0 broken-image surfaces.
- 0 public private-preview-copy surfaces.
- 0 legacy-structure surfaces.
- 28 representative, changed-editorial, or decision-state screenshots.
- Live Wayfair comparison confirmed a layered public IA: utility services, dominant search, intentional primary navigation, department navigation, and dense discovery paths.

## Remaining declared decisions

- `/checkout/confirm` requires a guarded empty-session contract.
- `/wishlist` requires a real feature or removal of every public promise.
